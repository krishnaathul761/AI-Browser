Phase 3 — Week 3 Acceptance Gate

Complete verification checklist and interactive testing runner for Sahayak browser agent.

Acceptance Gate Criteria (10 of 10)
✓
1. Elements numbered reliably on practice pages

Buttons, inputs, selects, links detected; stable 1-based sequential numbers; Shadow DOM overlay badges isolated from page CSS.

Validated by content/scanner.js + content/overlay.js
✓
2. Find-it identifies and highlights, no auto-action

Natural-language query maps to target element, scrolls into view and pulses glow; NEVER clicks or types.

Validated by FIND_ELEMENT + HIGHLIGHT_ELEMENT routes
✓
3. Agent JSON validated before use

Strict parser removes markdown fences; verifies target element presence in active scan map; blocks typing on sensitive fields (password/card/OTP).

Validated by background/agent/schema.js (validateAgentAction)
✓
4. No action before Approve

Autonomous loop strictly pauses in awaiting_approval; proposal card surfaces action, target element, and reason before any DOM execution.

Validated by background/agent/loop.js human-in-the-loop gate
✓
5. Approve, Skip, Stop, step limit, dry-run

Approve triggers EXECUTE_ACTION; Skip advances without executing; Stop immediately halts loop; max steps limit enforced; Dry-run highlights target without DOM mutation.

Validated by agentApprove, agentSkip, agentStop, dryRun branch
✓
6. Progress saved across Service Worker sleep

agentSession written to chrome.storage.local on every step; restored seamlessly upon worker wake-up or panel reopen.

Validated by background/agent/persist.js + AGENT_STATE_GET
✓
7. Action log preserved

Global actionLog[] records step, proposal, reason, decision (approved/dry-run/skipped/stopped), capped at 200 items in storage; viewable & clearable in panel.

Validated by appendActionLog + ACTION_LOG_GET/CLEAR
✓
8. Two practice errands succeed

Practice Errand 1 (multi-step form application) and Practice Errand 2 (e-commerce search and filter) complete with approval at every step.

Validated on internship-form.html and shop.html
✓
9. One-click skills + import/export (Slice 4.2)

Skills library supports create, edit/rename, delete, run across Summarise/Chat/Agent tabs; seed skills bundled; export/import with JSON schema validation & safety blocking.

Validated by background/router.js + SKILLS_* handlers & unit checks
✓
10. Safety rails: code, not just prompts (Slice 4.3)

Strict code barriers block banking/payment/UPI hosts & paths, internal browser protocols, and Web Store; automated typing into password, card, and OTP fields is rejected with SAFETY_REFUSAL; consequential actions (submit/pay/delete) require explicit two-step confirmation.

Validated by background/safety/{pages,fields,actions}.js
