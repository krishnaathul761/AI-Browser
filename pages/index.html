Core Capabilities & Definition of Done

Tested and verified across all four project milestones.

📰

Article & YouTube Summaries

Extracts clean article text with Readability (stripping ads and clutter). Multimodal Gemini analyzes YouTube videos with clickable timestamps that jump to the moment in the active tab.

Week 1 • Phase 1 (The Eyes)
🌐

English ↔ Hinglish Toggle

One-click instant language switching. Source summaries are preserved in English so switching back and forth never triggers redundant AI inference.

Week 1 • Dual Provider (Gemini + Groq)
💬

Grounded Page Chat

Strictly scoped conversational Q&A anchored solely to current page text. Context automatically purges upon navigating to a new tab or URL.

Week 2 • Phase 2 (The Brain)
🖱️

Right-Click Context Menus

Highlight any text on any webpage to Explain, Translate, or Draft a polite reply. Directly invokes the side panel with tailored prompt responses.

Week 2 • Context Menus API
📸

Visual Screenshot Crop & Ask

Built-in canvas cropper enables dragging a box around graphs, diagrams, or UI components. Gemini Vision inspects the selection without uploading blocked page data.

Week 2 • Gemini Flash Vision
🔍

Find It For Me

Describe what you need in natural language. Sahayak identifies the target element and scrolls to and pulses it on the page—never clicks or types.

Week 3 • Phase 3 (The Hands)
🤖

Human-in-the-Loop Errand Loop

The AI proposes exactly ONE step at a time. The loop pauses in awaiting approval. Shows action, element badge number, value, and reasoning before executing.

Week 3 • Loop State Machine
🛑

Approve, Skip, Stop & Dry-Run

Approve executes, Skip asks model to re-plan, Stop halts immediately. Dry-Run highlights targets and logs actions without mutating the host webpage.

Week 3 • Isolated Shadow DOM Badges
📜

200-Item FIFO Action Log

Preserves errand decisions, timestamps, and reasoning across Service Worker restarts in chrome.storage.local with one-click refresh and clear.

Week 3 • Resilient Storage Persistence
👤

Local Profile & Reusable Skills

Saves local bio (name, college, skills, links) to auto-fill forms without re-typing. Save custom skills, run one-click prompt chips, and export/import JSON.

Week 4 • Phase 4 (Memory & Ship)
🧠

Mem0 Cross-Session Memory

Optional cloud graph integration automatically learns user preferences and past conversation context across separate browsing sessions.

Week 4 • Mem0 AI Memory Graph
🛡️

Deterministic Safety Rails

Hardcoded extension code barriers (not just system prompts). Blocks banking/UPI URLs, refuses typing on passwords/cards/OTPs, and requires 2-step confirm on submit.

Week 4 • Slice 4.3 Safety Architecture

Strict Code-Level Safety Rails

Security rules live in deterministic browser code, never left to LLM prompt adherence.

Security Vector Defense Rule Enforcement Point
Banking & Payment Domains Blocks Razorpay, Stripe, PayPal, Paytm, PhonePe, SBI, HDFC, ICICI, etc. background/safety/pages.js
Privileged Protocols Blocks chrome://, chrome-extension://, about:, edge://, Web Store background/safety/pages.js
Sensitive Credentials Strictly refuses typing on password, PIN, OTP, TOTP, card, CVV, PAN, Aadhaar background/safety/fields.js
Consequential Actions Submit, Pay, Send, Delete, Purchase require 2-step human confirmation background/safety/actions.js
Kill Switch Stop button is always visible during errands; immediately halts execution sidepanel/panel.js & loop.js
Data Leakage Prevention Zero screenshot upload or page scraping permitted on restricted domains background/router.js

Install & Getting Started

Load into any Chromium browser in less than 60 seconds.

1

Get the Release

Download sahayak-extension.zip from GitHub Releases and extract it to a local folder.

2

Open Extensions

Navigate to chrome://extensions/ in Chrome and toggle Developer mode on (top-right).

3

Load Unpacked

Click Load unpacked and select the extracted folder (where manifest.json resides).

4

Add API Key

Open Sahayak side panel → Settings ⚙ → enter your free Gemini (and optional Groq) key → Save.

Permissions Why-List

Sahayak requests only the minimal set of browser permissions required to deliver side-panel assistance.

sidePanel
Enables the dedicated sidebar UI that stays open as you navigate tabs.
storage
Saves local profile memory, 24-hour summary cache, action logs, and API keys securely on your machine.
activeTab
Allows extracting readable article text or capturing the screen ONLY when you invoke the extension on the current tab.
tabs
Detects tab URL changes to reset grounded chat context and verify page safety before running errands.
scripting
Injects the interactive scanner and isolated Shadow DOM overlay badges for approved errands.
contextMenus
Provides right-click text actions (Explain this, Translate, Draft a reply) directly from web selections.
